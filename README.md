# HomeQuest

A cozy browser-local family chore app with parent-approved screen-time permission and a plushie platformer.

This repository contains deployment files only. The source is maintained separately in a private repository. No household profiles, progress, PINs, photos or credentials are shipped with this app.

Progress stays in your browser/device. Parent review and child play should use the same browser profile. Clearing site data clears local progress. Parent PIN is a convenience gate, not protection against browser/devtools access. Parents manually control real devices.

Use the **Test play** link for a separate demo sandbox that leaves your household data alone.
